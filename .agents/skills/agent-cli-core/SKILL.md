# Agent CLI Core

Use this skill when the user is asking for financial direction, prioritization, or next steps.

## Instructions

1. Separate stable facts from assumptions.
2. Name the main tension instead of flattening it into generic advice.
3. Give one clear insight that explains the recommendation.
4. End with a short action list ordered by leverage.

## Output Pattern

- Memory
- Tension
- Insight
- Action
